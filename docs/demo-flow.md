# CareerOS AI — 面试官体验路线(3~5 分钟)

> 目标:让面试官用最短时间看到产品闭环、AI 能力与工程质感。
> 本路线基于当前代码的真实实现,全部步骤均可在 Mock 模式下复现(零 API 成本)。

## 开始前(准备,约 1 分钟)

1. 按 [README](../README.md)「本地运行」启动项目,打开 http://localhost:3000
2. 注册一个新账号(邮箱 + 密码)——Mock 模式无需任何模型 Key
3. 按下面的顺序体验:职业画像 → 成长路线图 → 岗位匹配 → 90 天提升计划 → 简历优化 → 模拟面试

## 第 1 步:完成职业画像(约 1 分钟)

**做什么**:工作台点击「开始职业探索」(或顶栏「职业画像」),完成四步采集(教育 → 技能 → 经历 → 兴趣与目标)。

**看什么**:

- AI 画像概要:画像摘要、能力标签、优势、2-4 个推荐方向(带匹配度)、六维雷达、发展建议
- 「这不是我」纠偏入口:选择不准确的部分 → 全量重算 → 生成新画像版本,旧版本仍可查看对比

**为什么重要**:这是产品核心洞见的落地——「大部分人不是写不好简历,而是不知道该做什么」。用户第一次感到「被 AI 理解」,是留存的关键一步。

**体现的能力**:画像分析 Agent 的结构化输出(摘要 / 标签 / 方向 / 雷达一次成型,Schema 强校验);画像版本不可变快照 → 纠偏可对比、可回看。

## 第 2 步:从画像直达成长路线图(约 30 秒)

**做什么**:画像结果页点击「规划成长路线」。

**看什么**:

- 画像推荐的 2-4 个方向**自动带出**,无需重新输入;选择方向 + 每周投入时间 → AI 生成 3-4 阶段路线图
- 纵向时间线上的任务三态(待开始 / 进行中 / 已完成,可撤销)
- 「太难了 / 已经会了」反馈 → 仅重新生成当前阶段,其他阶段不动

**为什么重要**:体现「数据复利」——上一环节的 AI 产出直接成为下一环节的输入,用户零重复劳动。

**体现的能力**:路线规划 Agent 支持全量 + 单阶段重生成两种模式;跨模块数据流转设计。

## 第 3 步:岗位匹配(约 1 分钟)

**做什么**:顶栏「岗位匹配」,粘贴一份目标岗位的 JD(任意岗位的职位描述原文即可)。

**看什么**:

- 匹配度大数字 + 结构化拆解:必备 / 加分 / 隐性要求
- 逐项对比(匹配 / 部分匹配 / 差距 + 证据)+ 用户 vs 岗位双线雷达图
- 隐性需求揭示:JD 没写但岗位实际需要的
- 纠偏闭环:某条要求点「我其实满足」→ 补充信息 → 重新匹配,结果随之更新

**为什么重要**:招聘平台的 AI 只做关键词匹配,这里做的是「理解用户 vs 理解岗位」,回答求职的核心问题「我差在哪」。

**体现的能力**:岗位匹配 Agent 的结构化拆解;纠偏反馈结构化落库并触发重算。

## 第 4 步:90 天提升计划(约 30 秒)

**做什么**:在匹配报告页一键发起技能分析(目标岗位、差距清单、画像基线自动带出,无需重复输入)。

**看什么**:

- 差距优先级矩阵(重要性 × 差距大小)
- 13 周周计划:每周主题、任务、预估时长、产出要求、完成标准
- 资源推荐:免费优先,标注免费 / 付费

**为什么重要**:从「知道差距」到「有行动路径」——职业建议只有可执行才有价值。

**体现的能力**:技能教练 Agent 的时间预算一致性(周任务量与每周投入时间匹配,echo 交叉校验);优先级由「重要性 × 差距」确定性归一化,不信任模型自报标签。

## 第 5 步:简历优化(约 1 分钟)

**做什么**:顶栏「简历优化」,粘贴一段简历文本(或上传 PDF / Word 文件,本地开发无需额外配置)。

**看什么**:

- 解析 → 核对修正界面:结构化信息可逐项修正后保存
- 逐条改写对比卡:原文 / 改写文 / 折叠的「为什么这样改」,每条可接受 / 拒绝且可撤销
- ATS 评分 + 改进建议(显式按钮触发)
- 复制最终文本 + 应用内 PDF 预览
- (可选)顶栏「简历中心」:多份简历并存,同一简历可生成多个目标方向版本

**为什么重要**:与「一键重写」类工具的区别——先理解用户(画像 + 目标方向)→ 逐条可解释的改写 → 用户裁决。

**体现的能力**:改写 Agent「不改事实、只重建叙事」的边界约束;ATS 评分 = 确定性规则 + LLM 评估结合,评分 Agent 温度 0 保证稳定。

## 第 6 步:模拟面试(约 1 分钟)

**做什么**:顶栏「模拟面试」,选面试类型(行为面 / 技术面 / 案例面)与 5 题短面试,回答 1-2 题(可点一次「追问」),然后结束面试查看综合报告。

**看什么**:

- 出题个性化:题目来自你的简历与目标岗位
- 每题即时评估:内容 / 表达 1-10 分 + 改进建议 + 至多一次追问
- 打字机渲染与「面试官正在思考」等待气泡
- 综合报告:总体评价、突出优势、主要短板、1-2 个重点改进方向(不罗列问题清单)

**为什么重要**:补上闭环的最后一环「我能过吗」;刷新页面可从中断处继续,回答不丢失。

**体现的能力**:出题 / 评估 / 报告三个面试 Agent 接力;无流式基建下用「完整落库 + 进度轮询 + 前端逐字渲染」实现流畅等待体验。

## 可选:个人成长报告、分享卡与深色模式

- 工作台「成长区块」→ 完整报告页:画像版本演进 sparkline、能力变化双线雷达、任务完成趋势、匹配度变化;匿名聚合基准(≥5 人脱敏统计,标注「示例」)
- 画像 / 路线图页可生成分享卡 PNG(客户端截图)
- 头像菜单「外观」切换深色模式(跟随系统 / 浅色 / 深色三态)

## 演示贴士

- 全程 Mock 模式,不需要任何 API Key、不产生费用;想体验真实模型,`.env` 改 `LLM_PROVIDER=deepseek` 并填入 `DEEPSEEK_API_KEY`
- 想演示数据复利:更新或纠偏画像后再跑一次岗位匹配,分析基于新画像变化
- 想演示恢复能力:面试进行到一半刷新页面,可从中断处继续
- 移动端:窗口缩到 768px 以下,导航折叠为汉堡 + 抽屉
