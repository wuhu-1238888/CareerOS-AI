## 二、详细画像

### P1：林小月 — 方向迷茫的大学生

```
"我学了一个不知道能做什么的专业，身边的人都在卷互联网，
但我不知道我适不适合。"
```

#### 基本信息

| 属性 | 值 |
|------|-----|
| 年龄 | 21岁 |
| 学历 | 本科在读（大三） |
| 专业 | 市场营销 |
| 学校 | 某双非一本 |
| 城市 | 成都 |
| GPA | 3.2/4.0 |
| 实习经历 | 1段（某中小企业新媒体运营，3个月） |

#### 背景故事

林小月高考时报考市场营销专业，只是因为"听起来还行"。大三上学期，室友们开始疯狂找实习，她突然意识到自己并不知道毕业后要做什么。

她刷过大量职业规划的视频，尝试过做MBTI和霍兰德测试，结论是"适合做与人打交道的工作"——但这和没说一样。她在小红书上看到"AI产品经理"很火，但又觉得自己专业不对口、没有技术背景，不敢尝试。

她的焦虑是：**"不是我不想努力，是我不知道该往哪个方向努力。"**

#### 职业目标

- 短期：确定1-2个可行的职业方向
- 中期：通过实习或项目积累经验
- 长期：不清楚，需要探索

#### 核心痛点

| 痛点 | 严重程度 | 描述 |
|------|----------|------|
| 方向迷茫 | ★★★★★ | 专业与市场脱节，不知道什么方向适合自己 |
| 信息过载 | ★★★★☆ | 网上信息太多太杂，无法判断什么路径靠谱 |
| 信心不足 | ★★★★☆ | 双非背景，觉得好机会轮不到自己 |
| 能力模糊 | ★★★☆☆ | 不确定自己有什么能力，也不会表达 |

#### 技术能力

- 日常使用：微信、小红书、抖音、B站
- 工具使用：Office三件套、Canva
- AI接触度：用过ChatGPT做作业，但对AI原理完全不了解
- 设备：手机为主，电脑为辅

#### 决策因素

1. 方向是否"听起来有前景"（受社交媒体的影响大）
2. 门槛是否"我能够得着"（不会轻易挑战高难度方向）
3. 路径是否"有人走过"（需要案例和榜样）

#### 使用 CareerOS 的典型场景

1. 被小红书/B站博主的求职焦虑内容触发
2. 搜索"怎么知道自己适合做什么工作" → 发现 CareerOS
3. 注册后输入基本教育背景和模糊兴趣
4. 期望得到：**具体可行的职业方向建议**，而不是泛泛的"做你喜欢的"
5. 如果系统告诉她"以你的背景，AI产品经理是可达的，这是路径"——她会成为忠实用户

### P2：陈一凡 — 焦虑的应届毕业生

```
"投了60多份简历，只有3个面试。我知道肯定是简历有问题，
但不知道问题出在哪。"
```

#### 基本信息

| 属性 | 值 |
|------|-----|
| 年龄 | 23岁 |
| 学历 | 硕士（应届） |
| 专业 | 计算机科学与技术 |
| 学校 | 某211高校 |
| 城市 | 武汉→想去深圳/杭州 |
| 实习经历 | 2段（某中厂后端开发、某创业公司全栈） |
| 求职状态 | 秋招+春招投递中，已投60+份 |

#### 背景故事

陈一凡的编程能力在同届算中等偏上，LeetCode刷了200题，项目经验也有。但秋招投了60多份简历，面试只有3个，最终0 Offer。他对比了拿到大厂Offer的同学，发现自己的技术未必差很多，但简历确实显得"不够专业"。

他在知乎上搜过无数"校招简历怎么写"，试过用超级简历改排版，但不知道改完的版本是不是真的变好了。他最大的困惑是：**"我明明会这些东西，为什么简历上看起来像个刚培训出来的？"**

#### 职业目标

- 短期：拿到互联网中大厂后端开发Offer
- 中期：2-3年内成为高级开发
- 长期：技术管理或架构师方向

#### 核心痛点

| 痛点 | 严重程度 | 描述 |
|------|----------|------|
| 简历表达差 | ★★★★★ | 项目经历写成了技术文档，缺乏亮点和成果 |
| 匹配度未知 | ★★★★☆ | 不确定自己和目标岗位的真实差距 |
| 面试表现弱 | ★★★★☆ | 技术问题能答，但行为面试不知道怎么说 |
| 竞争焦虑 | ★★★☆☆ | 看到同学拿到Offer，自我怀疑加剧 |

#### 技术能力

- 技术栈：Java、Spring Boot、MySQL、Redis、Docker
- 项目：2个学校的科研项目、1个外包项目
- AI接触度：用过GitHub Copilot写代码，GPT辅助学习
- 设备：电脑为主

#### 决策因素

1. 能不能帮我拿到面试（结果导向，非常功利）
2. 修改后的简历"看起来专业"（他需要外部确认）
3. 使用成本低（不想花太多时间学一个新工具）

#### 使用 CareerOS 的典型场景

1. 在又一次简历石沉大海后，搜索"AI简历优化" → 发现 CareerOS
2. 上传简历 → 系统自动解析并生成职业画像
3. 发现系统不仅优化了文字表达，还告诉他"你这个项目经历更适合强调系统设计能力，而不是罗列技术栈"
4. 根据他的目标（后端开发），系统重新编写了项目描述，突出成果和影响力
5. 期望：**简历改完后"肉眼可见的变好了"**，并且有针对特定岗位的版本

### P3：张明远 — 想跳槽的职场新人

```
"工作一年，我发现这份工作和我想的不一样。
但跳槽的话，我这一年经验能算什么水平？"
```

#### 基本信息

| 属性 | 值 |
|------|-----|
| 年龄 | 25岁 |
| 学历 | 本科 |
| 专业 | 电子信息工程 |
| 学校 | 某普通一本 |
| 工作经历 | 1年（某中型企业测试工程师） |
| 城市 | 南京 |
| 当前薪资 | 年薪12万 |
| 目标薪资 | 年薪18-25万 |

#### 背景故事

张明远毕业后进了一家通信公司做测试。一年下来，他发现自己不喜欢这个方向——工作内容重复、成长空间有限、和互联网行业脱节。他想转做产品经理，但简历上一年的测试经验似乎对产品岗没有任何加分。

他尝试在招聘App上看PM岗位的JD，发现大部分要求"1-3年产品经验"。他陷入了一个困境：**没有产品经验所以找不到产品工作，找不到产品工作所以永远没有产品经验。**

他不知道的是，测试经验其实培养了他的逻辑分析能力和需求理解能力——这些正是PM需要的。但他不会在简历中建立这种关联。

#### 职业目标

- 短期：转行互联网产品经理
- 中期：2年内成为能独立负责一个模块的PM
- 长期：高级PM或创业

#### 核心痛点

| 痛点 | 严重程度 | 描述 |
|------|----------|------|
| 经验不匹配 | ★★★★★ | 现有经验无法直接迁移到目标岗位 |
| 能力不自信 | ★★★★☆ | 不确定自己是否能胜任产品经理 |
| 学习方向不清 | ★★★★☆ | 网上PM课程太多，不知道哪些真正有用 |
| 薪资预期不明 | ★★★☆☆ | 不知道转行后薪资会跌还是涨 |

#### 技术能力

- 技术栈：Python脚本、SQL、测试工具
- AI接触度：用过AI工具但了解不深
- 学习方式：B站课程 + 即刻/知乎 + 付费社群
- 设备：电脑 + 手机

#### 决策因素

1. 转行路径是否清晰可执行（需要明确的时间线和里程碑）
2. 过往经验是否能被"重新定义"（而不是从零开始）
3. 有没有相似背景的人成功转型的案例

#### 使用 CareerOS 的典型场景

1. 在即刻上看到有人用AI做职业规划 → 搜索 → 发现 CareerOS
2. 输入当前背景和目标方向 → 系统生成职业画像
3. 系统分析显示：他的测试经验中包含"需求分析"和"问题定位"能力，与PM能力有40%的重叠
4. 系统生成6个月转型计划：第1个月学产品基础 → 第2个月做产品分析项目 → 第3-4个月优化简历投递 → ...
5. 期望：**知道自己"不是从零开始"，并有一条清晰的转型路线**

### P4：赵雪莉 — 重新出发的转行者

```
"做了3年行政，我发现自己不能再这样下去了。
但我这个背景，除了行政还能做什么？"
```

#### 基本信息

| 属性 | 值 |
|------|-----|
| 年龄 | 28岁 |
| 学历 | 本科 |
| 专业 | 行政管理 |
| 工作经历 | 3年（某传统企业行政专员） |
| 城市 | 西安 |
| 当前薪资 | 年薪8万 |
| 目标薪资 | 年薪15万+ |

#### 背景故事

赵雪莉大学毕业后听家里安排进了一家国企做行政。3年过去，她发现自己每天的工作就是"填表、开会、传话"，没有任何成长。同届的同学有的已经在互联网公司做到小组Leader，而她连OA系统之外的工具都没用过。

她想要改变，但有几个现实问题：28岁的年龄在求职市场上已经不占优势；3年行政经验在互联网行业几乎等于"白纸"；她的转行试错成本比应届生高很多（有房租、有生活压力）。

她最怕的是：**"我花了半年时间学了新技能，结果发现转行失败，时间浪费了，储蓄也花光了。"**

#### 职业目标

- 短期：找到行政经验可迁移的互联网岗位（如HR、运营、项目助理）
- 中期：在新岗位积累2年后寻求更大的发展
- 长期：稳定且有成长空间的职业

#### 核心痛点

| 痛点 | 严重程度 | 描述 |
|------|----------|------|
| 经验价值怀疑 | ★★★★★ | 觉得过去3年的经验毫无价值 |
| 年龄焦虑 | ★★★★★ | 28岁转行，担心已经太晚 |
| 试错成本高 | ★★★★☆ | 不能像学生一样"慢慢探索" |
| 技能断层 | ★★★★☆ | 数字化技能几乎为零 |
| 社交圈局限 | ★★★☆☆ | 周围没有互联网行业的朋友可以参考 |

#### 技术能力

- 熟练使用：Office全系（Excel能力较强）
- AI接触度：听说过ChatGPT但没用过，不知道AI能怎么帮到自己
- 优点：沟通协调能力强，做事细致有条理
- 设备：电脑 + 手机

#### 决策因素

1. 转行路径的确定性和可执行性（必须"大概率能成"才会行动）
2. 需要看到"同样背景的人做到了"的真实案例
3. 每一步的时间成本和金钱成本要可控

#### 使用 CareerOS 的典型场景

1. 深夜刷手机，在微信上看到一篇"30岁转行还来得及吗"的文章
2. 对文章里提到的AI职业规划工具产生兴趣 → 访问 CareerOS
3. 输入背景后，系统告诉她：3年行政经验中包含的"沟通协调""流程管理""数据整理"能力，可以映射到互联网运营、HRBP、项目管理等方向
4. 系统给出每条路径的可行性分析、薪资预期、学习计划和预计转型时间
5. 期望：**被"看见"——她的经验不是零价值的，她只是需要换一种方式表达和运用**

## 四、用户需求层次

借鉴马斯洛需求层次，用户在 CareerOS 中的需求也呈阶梯式上升：

```
          ┌──────────────────────┐
          │  5. 职业成就感        │  ← "我不仅找到了工作，还找到了方向"
          │     (长期留存)        │
          ├──────────────────────┤
          │  4. 持续成长感        │  ← "系统帮我追踪进步，我越来越强"
          │     (周期性回访)      │
          ├──────────────────────┤
          │  3. 表达提升感        │  ← "我的简历和面试表现变好了"
          │     (功能深度使用)    │
          ├──────────────────────┤
          │  2. 路径清晰感        │  ← "我知道接下来该做什么了"
          │     (激活关键行为)    │
          ├──────────────────────┤
          │  1. 自我认知清晰感    │  ← "AI理解我是谁，我能做什么"
          │     (首次体验核心)    │
          └──────────────────────┘
```

**MVP 聚焦第1-3层**：先让用户感受到"被理解"和"有方向"，再逐步向上构建。

## 五、画像对产品设计的启示

| 设计启示 | 来源画像 | 具体指导 |
|----------|----------|----------|
| 首次使用要"低门槛" | P1、P4 | 不要求填大量信息，能基于最少输入给初步分析 |
| 结果要"可执行" | 所有 | 方向建议必须附带具体行动步骤，不能停留在概念 |
| 表达要"说人话" | P1、P4 | 技术概念需要解释，不能假设用户懂AI |
| 案例要"有代入感" | P1、P3 | 展示相似背景用户的成功路径，建立信心 |
| 分析要"有依据" | P2、P3 | 不能凭空给建议，要说清楚"为什么推荐这个方向" |
| 数据要"可视化" | 所有 | 能力雷达图、匹配百分比、成长时间线比文字更有说服力 |
